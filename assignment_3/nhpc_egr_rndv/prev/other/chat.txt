Task1: Implement the eager protocol which will take the input buffer that is passed in myverbs_send to a pre allocated buffer which you did in myverbs_init and then you are free to send the data to the target via channel or memory semantics. On the target side, once you receive data (as part of myverbs_recv call you may want to poll the CQ for any activity), copy the data from preallocated buffer to the user buffer as mentioned in myverbs_recv.

Please note that you would need to divide the user buffer pointer into smaller chunks as preallocated buffers may only be of smaller size, say 128KB. So, if the user attempts to do 512KB transfer, this process should happen 512KB/128KB = 4 times.

This would mean that you do the memory registration first and exchange the handle via channel semantics of verbs (again during the myverbs_init you can create QPs and setup the channel and prepost work). Once the handle (rkey and address) is ready, you can do then do RDMA write with immediate to perform the transfer.

1. Modified mpi-latency.c
This version aligns the memory to page boundaries (4KB), starts the benchmark loops at 4096 bytes, and replaces standard MPI point-to-point calls with myverbs equivalents.

C
#include <mpi.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/time.h>
#include "myverbs.h" /* Custom verbs header */

#define MAX_SIZE (1024*1024*4)
#define ITERATIONS 100
#define WARMUP     10
#define PAGE_SIZE  4096

int main(int argc, char **argv) {
  int size, rank, src_rank=0, dst_rank=1;
  char *src=NULL, *dst=NULL;
  int i;
  struct timeval start, end;
  float total_time=0;

  if(argc > 1) src_rank = atoi(argv[1]);
  if(argc > 2) dst_rank = atoi(argv[2]);

  printf("Latency benchmark between src_rank=%d and dst_rank=%d\n", src_rank, dst_rank);

  /* allocate page-aligned memory */
  if (posix_memalign((void**)&src, PAGE_SIZE, MAX_SIZE) != 0 || 
      posix_memalign((void**)&dst, PAGE_SIZE, MAX_SIZE) != 0) {
     perror("cannot allocate aligned memory\n");
     exit(0);
  }

  MPI_Init(&argc, &argv);
  MPI_Comm_size(MPI_COMM_WORLD, &size);
  MPI_Comm_rank(MPI_COMM_WORLD, &rank);

  /* Initialize RDMA Verbs environment and preallocate 128KB Eager buffers */
  myverbs_init(rank, src_rank, dst_rank);

  /* warmup - starting at 4KB */
  for(size=4096; size <= MAX_SIZE; size *= 2) {
    for (i=0; i < WARMUP; i++) {
       if (rank == src_rank) {
         myverbs_send(src, size, dst_rank); 
         myverbs_recv(dst, size, dst_rank); 
       }
       else if(rank == dst_rank){
         myverbs_recv(dst, size, src_rank); 
         myverbs_send(src, size, src_rank); 
       }    
    }
  }

  /* benchmark */
  if(rank == src_rank)
    printf("%10s   %10s usecs\n", "Size", "Latency (usecs)");
  
  for(size=4096; size <= MAX_SIZE; size *= 2) {
    MPI_Barrier(MPI_COMM_WORLD);

    gettimeofday(&start, NULL);
    for (i=0; i < ITERATIONS; i++) {
       if (rank == src_rank) {
         myverbs_send(src, size, dst_rank); 
         myverbs_recv(dst, size, dst_rank); 
       }
       else if(rank == dst_rank) {
         myverbs_recv(dst, size, src_rank); 
         myverbs_send(src, size, src_rank); 
       }    
    }
    gettimeofday(&end, NULL);
    total_time = ((end.tv_sec - start.tv_sec) * 1000000.0 + (end.tv_usec - start.tv_usec))/2;
    total_time /= ITERATIONS;
    if(rank == src_rank)
      printf("%10d   %10.2f\n", size, total_time);
  }
  
  free(src);
  free(dst);
  MPI_Finalize();
  return 0;
}
2. Custom Verbs Implementation (myverbs.c)
This file implements the Eager and Rendezvous logic using libibverbs.

C
#include <infiniband/verbs.h>
#include <string.h>
#include <stdlib.h>
#include <stdio.h>
#include <mpi.h>

#define EAGER_BUF_SIZE (128 * 1024) // 128KB Eager Limit
#define RENDEZVOUS_THRESHOLD EAGER_BUF_SIZE

/* Context state */
struct ibv_context *context;
struct ibv_pd *pd;
struct ibv_cq *cq;
struct ibv_qp *qp;
struct ibv_mr *eager_send_mr;
struct ibv_mr *eager_recv_mr;
char *eager_send_buf;
char *eager_recv_buf;

/* Structure for exchanging memory handles in Rendezvous */
struct mr_info {
    uint64_t addr;
    uint32_t rkey;
};

void myverbs_init(int rank, int src_rank, int dst_rank) {
    /* 1. Open device, allocate PD, create CQ and QP (RC) */
    // [Standard libibverbs boilerplate omitted for brevity: ibv_get_device_list, ibv_alloc_pd, ibv_create_cq, ibv_create_qp]

    /* 2. Allocate and register Eager buffers */
    posix_memalign((void**)&eager_send_buf, 4096, EAGER_BUF_SIZE);
    posix_memalign((void**)&eager_recv_buf, 4096, EAGER_BUF_SIZE);
    
    eager_send_mr = ibv_reg_mr(pd, eager_send_buf, EAGER_BUF_SIZE, IBV_ACCESS_LOCAL_WRITE);
    eager_recv_mr = ibv_reg_mr(pd, eager_recv_buf, EAGER_BUF_SIZE, IBV_ACCESS_LOCAL_WRITE | IBV_ACCESS_REMOTE_WRITE);

    /* 3. Exchange QP information (LID, QPN, PSN) via MPI to connect QPs */
    // Use standard MPI_Send/MPI_Recv to exchange ibv_qp struct info and transition QPs to RTS state.
    
    /* 4. Pre-post Recv WR for eager messages */
    struct ibv_sge sge = { (uint64_t)eager_recv_buf, EAGER_BUF_SIZE, eager_recv_mr->lkey };
    struct ibv_recv_wr wr = {0}, *bad_wr;
    wr.wr_id = 1; 
    wr.sg_list = &sge;
    wr.num_sge = 1;
    ibv_post_recv(qp, &wr, &bad_wr);
}

void myverbs_send(char *buf, int size, int target_rank) {
    if (size <= RENDEZVOUS_THRESHOLD) {
        /* TASK 1: EAGER PROTOCOL */
        int offset = 0;
        while (offset < size) {
            int chunk = (size - offset > EAGER_BUF_SIZE) ? EAGER_BUF_SIZE : size - offset;
            
            /* Copy user buffer to preallocated pinned buffer */
            memcpy(eager_send_buf, buf + offset, chunk);
            
            /* Post Send (Channel Semantics) */
            struct ibv_sge sge = { (uint64_t)eager_send_buf, chunk, eager_send_mr->lkey };
            struct ibv_send_wr wr = {0}, *bad_wr;
            wr.opcode = IBV_WR_SEND;
            wr.sg_list = &sge;
            wr.num_sge = 1;
            wr.send_flags = IBV_SEND_SIGNALED;
            
            ibv_post_send(qp, &wr, &bad_wr);
            
            /* Poll CQ for send completion */
            struct ibv_wc wc;
            while (ibv_poll_cq(cq, 1, &wc) == 0);
            
            offset += chunk;
        }
    } else {
        /* TASK 2: RENDEZVOUS PROTOCOL */
        /* 1. Register User Memory dynamically */
        struct ibv_mr *user_mr = ibv_reg_mr(pd, buf, size, IBV_ACCESS_LOCAL_WRITE | IBV_ACCESS_REMOTE_READ);
        
        /* 2. Send MR handle via Eager channel to target */
        struct mr_info info = { (uint64_t)buf, user_mr->rkey };
        memcpy(eager_send_buf, &info, sizeof(info));
        
        struct ibv_sge sge = { (uint64_t)eager_send_buf, sizeof(info), eager_send_mr->lkey };
        struct ibv_send_wr wr = {0}, *bad_wr;
        wr.opcode = IBV_WR_SEND;
        wr.sg_list = &sge;
        wr.num_sge = 1;
        wr.send_flags = IBV_SEND_SIGNALED;
        
        ibv_post_send(qp, &wr, &bad_wr);
        
        /* Poll CQ for send completion */
        struct ibv_wc wc;
        while (ibv_poll_cq(cq, 1, &wc) == 0);

        /* 3. Wait for Target to pull the data (Target will RDMA Read, or we RDMA write). 
           In this implementation, the target will do RDMA READ and send a completion sync back. */
        while (ibv_poll_cq(cq, 1, &wc) == 0); // Wait for sync message from target
        
        /* Deregister */
        ibv_dereg_mr(user_mr);
    }
}

void myverbs_recv(char *buf, int size, int source_rank) {
    struct ibv_wc wc;
    
    if (size <= RENDEZVOUS_THRESHOLD) {
        /* TASK 1: EAGER PROTOCOL */
        int offset = 0;
        while (offset < size) {
            int chunk = (size - offset > EAGER_BUF_SIZE) ? EAGER_BUF_SIZE : size - offset;
            
            /* Poll CQ for receive completion */
            while (ibv_poll_cq(cq, 1, &wc) == 0);
            
            /* Copy data from preallocated buffer to user buffer */
            memcpy(buf + offset, eager_recv_buf, chunk);
            
            /* Pre-post next receive */
            struct ibv_sge sge = { (uint64_t)eager_recv_buf, EAGER_BUF_SIZE, eager_recv_mr->lkey };
            struct ibv_recv_wr wr = {0}, *bad_wr;
            wr.sg_list = &sge;
            wr.num_sge = 1;
            ibv_post_recv(qp, &wr, &bad_wr);
            
            offset += chunk;
        }
    } else {
        /* TASK 2: RENDEZVOUS PROTOCOL */
        /* 1. Receive sender's handle */
        while (ibv_poll_cq(cq, 1, &wc) == 0);
        struct mr_info remote_info;
        memcpy(&remote_info, eager_recv_buf, sizeof(remote_info));

        /* Pre-post receive for the next operation */
        struct ibv_sge recv_sge = { (uint64_t)eager_recv_buf, EAGER_BUF_SIZE, eager_recv_mr->lkey };
        struct ibv_recv_wr recv_wr = {0}, *bad_recv_wr;
        recv_wr.sg_list = &recv_sge;
        recv_wr.num_sge = 1;
        ibv_post_recv(qp, &recv_wr, &bad_recv_wr);

        /* 2. Register local buffer for RDMA Read destination */
        struct ibv_mr *local_mr = ibv_reg_mr(pd, buf, size, IBV_ACCESS_LOCAL_WRITE);

        /* 3. Execute RDMA READ to pull data from sender */
        struct ibv_sge sge = { (uint64_t)buf, size, local_mr->lkey };
        struct ibv_send_wr wr = {0}, *bad_wr;
        wr.opcode = IBV_WR_RDMA_READ;
        wr.sg_list = &sge;
        wr.num_sge = 1;
        wr.send_flags = IBV_SEND_SIGNALED;
        wr.wr.rdma.remote_addr = remote_info.addr;
        wr.wr.rdma.rkey = remote_info.rkey;
        
        ibv_post_send(qp, &wr, &bad_wr);
        
        /* Poll CQ for RDMA Read completion */
        while (ibv_poll_cq(cq, 1, &wc) == 0);

        /* 4. Send a 0-byte message back to sender to unblock them (Sync) */
        struct ibv_send_wr sync_wr = {0};
        sync_wr.opcode = IBV_WR_SEND;
        sync_wr.send_flags = IBV_SEND_SIGNALED;
        ibv_post_send(qp, &sync_wr, &bad_wr);
        while (ibv_poll_cq(cq, 1, &wc) == 0);

        ibv_dereg_mr(local_mr);
    }
}

Run the Unmodified MPI Benchmark: Compile the original mpi-latency.c with mpicc mpi-latency.c -o mpi-latency and execute it to establish your baseline latency graph.

Expected Outcomes:

Eager Protocol (4KB - 128KB): The verbs Eager implementation will likely perform similarly to or slightly better than standard MPI due to bypassing the MPI progression engine overhead, but the memory copy (memcpy to pinned buffer) will still bound the latency.

Rendezvous Protocol (256KB - 4MB): You will observe a latency spike precisely at the 128KB -> 256KB transition. This is the cost of dynamic memory registration (ibv_reg_mr) which is notoriously expensive. However, once registered, the actual zero-copy RDMA READ bypasses CPU copies entirely, maximizing PCIe/network bandwidth for large payloads. Standard MPI mitigates the ibv_reg_mr cost by utilizing internal Registration Caches (RegCache); your custom implementation will likely be slower at large message sizes unless you implement a similar memory registration cache.

To compare the Eager and Rendezvous protocols side-by-side for every message size, the benchmark loop must be run twice: once forcing the Eager chunking protocol, and once forcing the Rendezvous dynamic registration protocol.

Here is the modified mpi-latency.c that evaluates both protocols across all sizes (4KB to 4MB) and outputs a combined comparison table.

Custom Verbs Implementation (myverbs.c)
This splits the send and receive logic into discrete functions so they can be called independently for all message sizes. The chunking logic in the Eager protocol remains, meaning a 4MB transfer will trigger 32 separate 128KB Eager transfers, while Rendezvous will handle the 4MB payload as a single zero-copy RDMA Read.

C
#include <infiniband/verbs.h>
#include <string.h>
#include <stdlib.h>
#include <stdio.h>

#define EAGER_BUF_SIZE (128 * 1024) // 128KB chunk size for Eager

/* Context state */
struct ibv_context *context;
struct ibv_pd *pd;
struct ibv_cq *cq;
struct ibv_qp *qp;
struct ibv_mr *eager_send_mr;
struct ibv_mr *eager_recv_mr;
char *eager_send_buf;
char *eager_recv_buf;

struct mr_info {
    uint64_t addr;
    uint32_t rkey;
};

void myverbs_init(int rank, int src_rank, int dst_rank) {
    // 1. Hardware initialization and QP creation (boiler plate omitted)
    
    // 2. Preallocate and register static Eager buffers
    posix_memalign((void**)&eager_send_buf, 4096, EAGER_BUF_SIZE);
    posix_memalign((void**)&eager_recv_buf, 4096, EAGER_BUF_SIZE);
    
    eager_send_mr = ibv_reg_mr(pd, eager_send_buf, EAGER_BUF_SIZE, IBV_ACCESS_LOCAL_WRITE);
    eager_recv_mr = ibv_reg_mr(pd, eager_recv_buf, EAGER_BUF_SIZE, IBV_ACCESS_LOCAL_WRITE | IBV_ACCESS_REMOTE_WRITE);

    // 3. Connect QPs via MPI_Send/Recv ...
    
    // 4. Pre-post initial receive for eager channels
    struct ibv_sge sge = { (uint64_t)eager_recv_buf, EAGER_BUF_SIZE, eager_recv_mr->lkey };
    struct ibv_recv_wr wr = {0}, *bad_wr;
    wr.sg_list = &sge;
    wr.num_sge = 1;
    ibv_post_recv(qp, &wr, &bad_wr);
}

/* ==========================================================
 * EAGER PROTOCOL: Memory copy to pre-registered buffers, chunked
 * ========================================================== */
void myverbs_send_eager(char *buf, int size, int target_rank) {
    int offset = 0;
    while (offset < size) {
        int chunk = (size - offset > EAGER_BUF_SIZE) ? EAGER_BUF_SIZE : size - offset;
        
        memcpy(eager_send_buf, buf + offset, chunk);
        
        struct ibv_sge sge = { (uint64_t)eager_send_buf, chunk, eager_send_mr->lkey };
        struct ibv_send_wr wr = {0}, *bad_wr;
        wr.opcode = IBV_WR_SEND;
        wr.sg_list = &sge;
        wr.num_sge = 1;
        wr.send_flags = IBV_SEND_SIGNALED;
        
        ibv_post_send(qp, &wr, &bad_wr);
        
        struct ibv_wc wc;
        while (ibv_poll_cq(cq, 1, &wc) == 0);
        
        offset += chunk;
    }
}

void myverbs_recv_eager(char *buf, int size, int source_rank) {
    struct ibv_wc wc;
    int offset = 0;
    while (offset < size) {
        int chunk = (size - offset > EAGER_BUF_SIZE) ? EAGER_BUF_SIZE : size - offset;
        
        while (ibv_poll_cq(cq, 1, &wc) == 0);
        
        memcpy(buf + offset, eager_recv_buf, chunk);
        
        // Repost the receive buffer
        struct ibv_sge sge = { (uint64_t)eager_recv_buf, EAGER_BUF_SIZE, eager_recv_mr->lkey };
        struct ibv_recv_wr wr = {0}, *bad_wr;
        wr.sg_list = &sge;
        wr.num_sge = 1;
        ibv_post_recv(qp, &wr, &bad_wr);
        
        offset += chunk;
    }
}

/* ==========================================================
 * RENDEZVOUS PROTOCOL: Dynamic memory registration & RDMA Read
 * ========================================================== */
void myverbs_send_rendezvous(char *buf, int size, int target_rank) {
    // 1. Register User Memory 
    struct ibv_mr *user_mr = ibv_reg_mr(pd, buf, size, IBV_ACCESS_LOCAL_WRITE | IBV_ACCESS_REMOTE_READ);
    
    // 2. Send Handle via eager channel
    struct mr_info info = { (uint64_t)buf, user_mr->rkey };
    memcpy(eager_send_buf, &info, sizeof(info));
    
    struct ibv_sge sge = { (uint64_t)eager_send_buf, sizeof(info), eager_send_mr->lkey };
    struct ibv_send_wr wr = {0}, *bad_wr;
    wr.opcode = IBV_WR_SEND;
    wr.sg_list = &sge;
    wr.num_sge = 1;
    wr.send_flags = IBV_SEND_SIGNALED;
    ibv_post_send(qp, &wr, &bad_wr);
    
    struct ibv_wc wc;
    while (ibv_poll_cq(cq, 1, &wc) == 0);

    // 3. Wait for Target to RDMA Read the data and send sync
    while (ibv_poll_cq(cq, 1, &wc) == 0); 
    
    // 4. Cleanup
    ibv_dereg_mr(user_mr);
}

void myverbs_recv_rendezvous(char *buf, int size, int source_rank) {
    struct ibv_wc wc;
    
    // 1. Receive sender's handle
    while (ibv_poll_cq(cq, 1, &wc) == 0);
    struct mr_info remote_info;
    memcpy(&remote_info, eager_recv_buf, sizeof(remote_info));

    // Pre-post for next eager/sync msg
    struct ibv_sge recv_sge = { (uint64_t)eager_recv_buf, EAGER_BUF_SIZE, eager_recv_mr->lkey };
    struct ibv_recv_wr recv_wr = {0}, *bad_recv_wr;
    recv_wr.sg_list = &recv_sge;
    recv_wr.num_sge = 1;
    ibv_post_recv(qp, &recv_wr, &bad_recv_wr);

    // 2. Register local buffer for RDMA Read destination
    struct ibv_mr *local_mr = ibv_reg_mr(pd, buf, size, IBV_ACCESS_LOCAL_WRITE);

    // 3. RDMA READ to pull data directly into user buffer
    struct ibv_sge sge = { (uint64_t)buf, size, local_mr->lkey };
    struct ibv_send_wr wr = {0}, *bad_wr;
    wr.opcode = IBV_WR_RDMA_READ;
    wr.sg_list = &sge;
    wr.num_sge = 1;
    wr.send_flags = IBV_SEND_SIGNALED;
    wr.wr.rdma.remote_addr = remote_info.addr;
    wr.wr.rdma.rkey = remote_info.rkey;
    
    ibv_post_send(qp, &wr, &bad_wr);
    while (ibv_poll_cq(cq, 1, &wc) == 0);

    // 4. Send 0-byte sync to unblock sender
    struct ibv_send_wr sync_wr = {0};

RoCE vs. InfiniBand (The LID = 0 Problem): The code I provided uses standard InfiniBand LID (Local Identifier) routing. If your university cluster uses RoCE (RDMA over Converged Ethernet) instead of traditional InfiniBand, your LID will always be 0. In RoCE, you cannot route via LID; you must exchange and route via GIDs (Global Identifiers) and MAC addresses. If the queue pair is given a destination LID of 0, it silently drops the packets.

Single-Node Loopback Drops: Both of your MPI ranks are running on the exact same physical node and sharing the same network port. In traditional InfiniBand, sending a packet out of a port to its own LID requires the physical network switch to support and be configured for "hairpin" or loopback routing. If the switch isn't configured for this, it drops the loopback packets.

Shared Completion Queue (CQ) Race Condition: Both your Send and Receive operations post their completion notifications to the exact same CQ. If a receive finishes slightly early and you happen to be polling the queue waiting for a send to finish, you will accidentally pop and discard the receive completion. When the code later explicitly waits for that receive, it will hang forever because the notification is already gone.

We are extremely close! The hardware initialized properly and the network is active, but the code hit a classic InfiniBand dead-end: CQ Mixing and RNR (Receiver Not Ready) Deadlock.

Here is exactly why it hung silently:

CQ Mixing: We were using a single Completion Queue (CQ) for both sending and receiving. In the Eager protocol, when a send completed at the exact same microsecond a message was received, the queue had two entries. The code popped the RECV completion but thought it was the SEND completion, permanently knocking the two ranks out of sync.

The RNR Deadlock: In the Rendezvous protocol, the target rank sends a "Sync" message to unblock the sender. However, the sender consumed that message without ever posting a replacement receive buffer. On the next loop, when Rank 0 tried to send, Rank 1 had no receive buffer ready, causing the InfiniBand hardware to endlessly reject the packet (RNR NAK) in an infinite hardware retry loop.

To fix this, I have split the completion queues into send_cq and recv_cq so they never mix, added the missing buffer repost in Rendezvous, and added context to the error logs so if anything goes wrong, it will print exactly which phase failed.
